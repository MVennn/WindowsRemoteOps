**首版：把「Windows 主机开通 SSH」这件事整理成能照着做、能自己排错的仓库。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/WindowsRemoteOps/issues/new/choose) 反馈 —— 请附 Windows 版本、执行的完整命令、报错原文。

## 本版内容

**开通与验证**

- 新增 `host/bootstrap-openssh.ps1` —— 目标机侧一次性开通：装 `OpenSSH.Server`、设自启并启动、放行 22、写 `administrators_authorized_keys` 并收紧 ACL（按 SID）；`-DisablePasswordAuth` 一键禁密码（自动插入正确作用域），重启前 `sshd -t` 预校验、失败自动回滚，重启后核对服务状态。
- 新增 `tools/verify-host.py` —— 操作机侧四项验收：密钥登录 / 命令执行 / 文件传输 / PowerShell 可用；`--dry-run` 只读探测，输出跨代码页不截断。

**文档**

- 新增 接入踩点（四个方案的取舍） / 架构与边界（会改什么） / 踩坑总汇 / 按现象排错 / 凭据位置索引。
- 新增 `host/host.conf.example` —— 主机配置模板（占位符），真值不入库。

**仓库**

- 新增 `check-docs.py` / `check-secrets.py` 守卫（含 RFC1918 内网 IP 扫描）与 CI；Issue 表单三件套。

---

需要一台局域网内可 ping 通的 Windows 10/11 主机与一台操作机；目标机侧脚本需要管理员 PowerShell。
执行前请先看 [ARCHITECTURE.md](../ARCHITECTURE.md) 的「会改什么」与 [SECRETS.md](../SECRETS.md)。
